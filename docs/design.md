# Before the Mess (가제) — 게임 설계 문서

> 유품 정리인 척하는 증거 인멸 호러. 정리 게임의 아늑함으로 시작해, 플레이어를 살인자의 손으로 만든다.

*작성일: 2026-09-11 / 최종 갱신: 2026-09-14 / 상태: 핵심 반전(딸 생존·찾기·분기)·공포 엔진·정리 방식·첫 방 확정 → 나머지 방 상세 설계 단계*

---

## 1. 한 줄 요약
낯선 집을 정리하는 힐링 게임인 줄 알았는데 — 사실 나는 이 가족을 살해한 강도이고, 지금 하는 "정리"는 전부 **증거 인멸**이었다. 그리고 게임 내내 찾아다닌 '무언가'는, 아직 못 죽인 이 집 **막내딸**이었다.

## 2. 장르 / 포지셔닝
- **장르**: 정리(Unpacking식) + 심리 호러
- **레퍼런스**: Unpacking(정리 메커니즘·시선) + Chilla's Art(한국형 저예산 호러 톤)
- **차별점**: "청소로 범죄 은폐"(Viscera Cleanup Detail류)에 **죽은 가족의 초자연적 이상현상(지켜봄)**과 **주제적 반전**을 얹음. 죄책감이 아니라 **차가운 인멸의 소름.**
- **엔진**: Godot
- **플랫폼**: PC (솔로 개발 스코프)

## 3. 톤
- 주인공은 **자기가 한 짓을 정확히 안다.** 죄책감 없음. **담담하게** 증거를 지운다.
- 공포는 주인공의 내면이 아니라 **바깥(집·죽은 가족)에서 온다.**
- 초자연 중심(지워지지 않는 흔적) + 정적·사운드 연출.

## 3.5 관통 설계 원칙 (확정 — 모든 결정의 기준)
> **설계 기둥: 잔잔한 정리 + 분위기 호러.** 난이도·실패·시간압박 없음. 재미의 축 = 정리 손맛 · 몰입 · 이야기 · 이상현상. (Unpacking의 아늑함 + Chilla's Art의 저음 공포)

1. **공포는 바깥에서.** 주인공은 담담(죄책감 X). 무서움은 집·죽은 가족에서 온다. (§3)
2. **범행 흔적·서사는 '조용한 암시'.** 대사·UI 없이 배치·디테일로만. 알아채면 알아채고 아니면 지나감. (능동적 공포는 아래 5번 이상현상으로 분리.) (§6.6)
3. **역순 청소 = 되돌리기.** 사건의 역순으로 치움 = "어질러지기 전으로" = 제목. (§6.5)
4. **정리는 정상 완수·유지 (되돌아오지 않음).** 치운 건 치워진 채 남음. 손맛 보존, 의미만 서늘(증거 인멸). (§4)
5. **공포 = 이상현상 레이어.** 정리를 막지 않고, 행동·환경에 반응해 잠깐 나타났다 사라지는 초자연 목격으로만 무섭게. (§8)
5-b. **중심 미스디렉션 (플레이 메커니즘 아님).** 독백 + 거의 안 보이는 간접 힌트로만 '무언가'를 찾음 = 사실은 살아 숨은 딸. 명시적 수색 행동 없음. 마지막에 소급해 "그게 다 딸 찾는 거였구나" 깨닫게. (§5.5·§7·§9)
6. **정리 흐름 = 다음 물건 제시 → 클릭해 집기.** 하단 중앙에 다음 물건이 뜸 → 클릭하면 커서가 되어 집어듦 → 배치. 흩어진 걸 찾을 필요 없음, 페이싱 제어. (§5)
7. **방 최소화.** 초기 스코프는 최소 공간. 필요하면 나중에 추가. (§6.5)
8. **집 전체·층은 화면에 안 드러남.** 방 하나씩 뷰. 층 배치는 설계 참고용일 뿐. (§6.5)
9. **자유 배치 + 열기.** 카테고리 존 안에선 좌표·각도 자유 / 서랍·찬장·문은 열림. (§5)

## 4. 코어 루프
```
방 진입 → 어질러진 상태(사실은 범행 흔적)
→ 다음 물건이 손에 → 제 존에 배치 / 핏자국 닦기
→ 정리 진행도 채움 → 다음 방 해금
→ (정리하는 내내) 내 행동에 반응해 이상현상이 스침 = 지켜보는 가족(§8)
```
겉보기엔 "어질러진 집을 정돈". 실제 의미는 **피 닦기·몸싸움 흔적 원상복구·지문 제거 = 증거 인멸.** 정리는 **정상적으로 완수되고 유지됨(되돌아오지 않음)**, 공포는 별개 이상현상 레이어로 얹힘. 손맛은 유지, 의미만 서늘해짐.

## 5. 정리 메커니즘 (Unpacking식)
- **정리 흐름 = 다음 물건 제시 → 클릭해 집기**: 다음 정리할 물건이 **화면 하단 중앙에 뿅 나타남** → **클릭하면 그 물건이 커서가 되어(집어듦)** → 존에 배치 → 손 비면 다음 물건이 또 나타남 → 다시 클릭. 한 번에 하나라 흩어진 걸 찾을 필요 없음(애매함 0). **공포 페이싱을 정확히 제어**(N번째 물건에 이상현상 걸기).
- **자유 배치**: 정확한 위치를 맞추는 게 아님. 플레이어가 **만족스러운 대로** 배치.
- **카테고리 제약만**: 물건은 "맞는 종류의 공간"에만 들어감. (예: 칫솔 → 화장실, 컵 → 부엌). 그 안에선 자유.
- **90° 회전**: 테트리스식. **우클릭으로 90°씩**, 4번 = 제자리. (방향성 있는 물건만 필요)
  - 구현: 대부분 스프라이트 1장 코드 회전. 방향성 강한 물건(램프·액자)만 4방향 그림.
- **판정 & 피드백**: 물건은 어디든 놓을 수 있으나, **틀린 존에 놓으면 아이템 테두리가 빨강(튀는 색)** = "여긴 아냐". 올바른 카테고리 존으로 옮기면 해제. 맞는 존 안에선 좌표·각도 자유. (Unpacking식)
- **핏자국 닦기**: 바닥·벽·표면의 핏자국은 물건 배치와 **별개 동작**으로 그 자리에서 닦음. 닦으면 지워지고 **유지됨(안 되돌아옴)**.
- **서랍·찬장 열기**: 웬만한 서랍·찬장·옷장은 여닫기 가능. 열어야 나오는 물건·흔적이 있음(협탁 서랍 속 일기, 신발장 찬장 잡동사니 등).
- **이상현상 트리거**: 물건 집기/놓기·서랍/옷장 열기·핏자국 닦기 그 순간에 이상현상 발동(§8). 정리 진행 자체엔 지장 없음.
- **앞뒤 가림**: 물건 화면 y값 낮을수록 앞 (y-sort 자동 정렬).

## 5.5 게임 진행 방식 (플레이 흐름 — 확정)

### 정체성 (설계 기둥)
**잔잔한 정리 + 분위기 호러.** 난이도·실패·시간압박 없음. 재미의 축 = 정리 손맛 · 몰입 · 이야기 · 이상현상.

### 한 방의 흐름
```
방 입장 → (어질러진 방 + 핏자국)
→ 하단 중앙에 다음 물건 제시 → 클릭해 집어 맞는 존에 배치(틀리면 빨강) (반복)
→ 병행: 표면·바닥의 핏자국을 발견하면 닦기
→ 공급 소진 + 핏자국 전부 닦임 = 방 100%
→ 벽 전등 스위치 활성화(유도) → 불 끄면 자동 페이드 → 다음 방(챕터)
```
- **완료 판정 = 전부 '올바른 존'에 배치(빨강 0) + 핏자국 전부 제거.** 진행도(놓은 수/전체) 우상단 표시.
- **물건 배치와 핏자국 닦기는 자유 병행** — 순서 강제 없음. 핏자국은 눈에 띄면 언제든.
- 정리 중 **이상현상**이 행동에 반응해 스침(§8) + 가끔 **독백**(§7 미스디렉션).

### 조작 · UI (확정)
- **커서 = 손 모양** (기본, 빈손). 물건을 집으면 **그 물건이 커서가 됨**(손 대신 물건). 놓으면 다시 손.
- **입력:** 마우스. 하단 중앙 물건 **클릭 = 집기** → 이동 → 클릭/놓기로 배치 / **우클릭 = 90° 회전** / 핏자국 위 **문지르기 = 닦기**.
- **다음 물건 제시:** 이전 물건 놓으면 하단 중앙에 다음 물건이 나타남(뿅). **클릭해야** 손에 들림.
- **진행도:** 우상단 **`놓은 수 / 전체`** (예: 7/14).
- **틀린 배치 = 빨강 테두리:** 틀린 존에 놓으면 아이템 테두리가 빨강(튀는 색) → 올바른 존으로 옮기면 해제.
- **전등 스위치 = 다이제틱 완료 게이트 (2단계):**
  - **비활성** — 정리 중 전체 + '다 놓았지만 빨강/핏자국 남음'까지 **동일하게 비활성.** 벽에 평범히 있음, 하이라이트 없음, 눌러도 무반응. = 아직 못 나감.
  - **활성** — **모두 올바른 존(빨강 0) + 핏자국 0**이 되는 순간 스위치 반짝(하이라이트) → 클릭하면 불 끄고 전환.
- **다 놓았는데 빨강 남으면:** 스위치가 안 켜지는 것으로 '안 끝남'을 알림 + 남은 빨강 아이템이 **은은하게 깜빡**(시선 유도). (필요 시 짧은 한 줄 보조)

### 딸 '찾기'는 플레이 메커니즘이 아님
- 명시적 수색 행동 없음. **독백만**으로 "뭔가 찾는 중"임을 흘림.
- 게임 곳곳에 **아주 간접적인 힌트 몇 개**(거의 알아채지 못할 정도)를 심음 → 마지막에 "찾던 게 딸이었다"를 깨달을 때 **소급적으로** "그게 다 이거였구나". (힌트는 요란하지 않게, 실제 목록은 §11 추후)

### 방 이동 · 길이 (확정)
- **방 전환 = 불 끄고 나가기.** 정면 뷰라 문은 화면 뒤(4번째 벽) → 문 대신 **벽 전등 스위치**로 마무리. 방 100% 되면 스위치 활성화(유도) → **끄면 자동 페이드 → 다음 방.** 어두워지는 순간 = 공포 비트·이상현상 얹기 좋음.
- **챕터 분할 = 방 1개 = 챕터** (총 8챕터). 챕터 클리어마다 저장, 메뉴에서 챕터 선택·이어하기.

## 6. 시점 / 뷰 (확정)
- **평면 정투영(front elevation).** Unpacking식 납작한 정면 방. 측벽 최소/없음, 원근 왜곡 0.
- 이유: **90° 자유 회전이 평면에서만 자연스럽게 성립.** 강한 투시 + 자유 회전은 공존 불가.
- **분위기는 각도가 아니라 조명·그레인·색감으로.** (분위기의 90%는 조명)

### 배경 설계 규칙
1. 정면 정투영, 측벽 최소 → 물건 눕혀도 맞음
2. 표면을 평평한 수평 띠(선반·책상·바닥)로
3. 원근 왜곡 0 → 어디 놔도 스프라이트 그대로
4. 조명 방향 일관(한 방향) → 물건 그림자와 안 싸움

### 에셋 파이프라인
- **무료 CC0 에셋**(Kenney, Quaternius, Poly Haven) → Blender 배치 → **정투영 렌더로 배경 이미지 뽑기.** (돈 0원)
- 게임 실행 중엔 3D 안 돌아감 = 순수 2D. **실시간 3D 조작 없음.**
- **상태별 배경을 같은 구도로 여러 장 렌더** → 공포 연출용. (AI 생성은 구도 일관성이 안 나와서 부적합. Blender 렌더가 정답.)
  - 예: `방_정상.png` / `방_불꺼짐.png` / `방_피묻음.png` / `방_액자얼굴지움.png`
- **앞뒤 가림**: 배경을 `뒷배경` + `앞가림`(물건을 가려야 할 앞쪽 요소만, 나머지 투명) 2겹으로 렌더. 물건은 그 사이에.

## 6.5 집 구조 — 낡은 2층 단독주택 (확정)

**뷰: 방 하나씩(Unpacking식).** 한 화면 = 한 방 정면. 방 이동 = 문 클릭 / 집 단면 미니맵.
**방 최소화 원칙** — 초기 스코프는 최대한 적은 방. 필요하면 나중에 추가.

### 층별 배치 (정면에서 본 집)
```
2층      [ 딸 방 ] [ 안방(부부) ] [ 아빠 서재 ] [ 화장실 ]
                    │     계단      │
1층    [ 할머니 방 ] [ 거실·식탁 ] [ 주방 ] [ 현관(→2층 계단) ]
```
> ※ **층 구분은 게임에 드러나지 않음**(방 하나씩 뷰 = 전체 집을 보여주지 않음). 위 배치는 설계 참고용일 뿐. 현실적으론 화장실이 1·2층 2개지만 **게임엔 1개(2층)만** 등장.

### 배치 논리
- **할머니 = 1층** — 노인, 계단 못 오름 → 리얼하고 동선 자연스러움.
- **삼촌 = 방 없음** — 거실에 얹혀 삶. 개인 물건 몇 개만 거실에 흩어져 있음(술병·차용증·현금봉투). "얹혀사는 존재 = 자기 공간조차 없음"의 소외.
- **안방(부부) = 아빠·엄마 같이 씀.** 서재는 아빠 개인 공간으로 별도.
- **거실·식탁 = 클라이맥스 무대 + 삼촌 흔적** — 정보 밀도 가장 높은 방. 청소 순서상 마지막 방(현관 직전).
- **주방 = 별도, 거실 바로 앞** — 냉장고·싱크·조리(컵·그릇 존). 흉기 부엌칼의 자리.
- **딸 방 = 첫 방(튜토리얼).** 겉보기 아늑한 중학생 방으로 "정리 게임인 척" 도입.
- **현관 = 마지막 방(엔딩 거울).** 청소를 다 마치고 나가는 곳. 2층 계단이 보임(집의 수직 동선). (아빠 계단 살해 현장은 서재 화면에 계단참으로 포함)

### 카테고리 존 (기능실 — §5 메커니즘 필수)
```
주방     : 컵·그릇·조리도구 / 냉장고 문(자석·사진)   화장실 : 세면류·수건
현관     : 신발·우산·열쇠·외투                    각 인물방 : 그 인물의 개인 물건
```

### 방 해금 = 정리 진행도(§4). 해금 순서 = 그날 밤 살해 순서의 **역순** (§7 타임라인)
```
1. 딸 방(첫 방·튜토리얼) → 2. 안방(엄마) → 3. 화장실 → 4. 아빠 서재·계단(아빠)
→ 5. 할머니 방 → 6. 주방 → 7. 거실·식탁(삼촌 + 클라이맥스) → 8. 현관(엔딩 거울)
```
- **역순 = 되돌리기.** 마지막 죽음(딸)부터 거꾸로 짚어, 첫 죽음이자 침입 지점(거실)에서 사건의 시작이 드러남. 제목 *Before the Mess*(어질러지기 전으로)와 정확히 맞물림.
- **딸 방이 첫 방** → 겉보기 아늑한 중학생 방으로 "정리 게임인 척" 도입. 딸이 이후 모든 방에서 가장 자주·가까이 나타나 끝까지 지켜봄(§8) = "제일 먼저 지운 아이가 제일 끈질기게 따라온다".
- **거실 = 클라이맥스** — 가족이 마지막 함께한 식탁 + 침입 지점. 이상현상이 절정에 달함(§8) → 바로 다음 현관 거울 엔딩.
- **화장실 = 안방 다음** (강도가 피 씻은 자기 흔적 지움, 2층), **주방 = 거실 바로 앞** (흉기 부엌칼 자리).

**스코프: 전체 공간 8개** (딸·안방·서재·할머니·거실·주방·화장실·현관). 삼촌은 별도 방 없이 거실. 프로토타입은 방 1개부터(§12).

## 6.6 방별 소품 · 가구 (초안)

표기: **가구/오브젝트** = 소품을 올리는 표면(=카테고리 존). **물건 목록** = 플레이어가 정리하는 소품 / *이면* = 범행·인멸의 의미.

> **원칙: 모든 이면은 '조용한 암시'로.** 대사·UI·튜토리얼로 설명하지 않고 오직 배치·디테일로만 드러냄. 플레이어가 알아채면 알아채고, 아니면 지나가도 됨. (요란한 장치 X)

> **인터랙션 규칙**: 웬만한 서랍·찬장·문은 **열고 닫을 수 있음**(신발장 상단 찬장, 협탁 서랍, 서랍장, 옷장 등). 열어야 나오는 물건·흔적이 있음.


※ 목록은 종류(대표 소품) 위주. 실제 배치 시 같은 종류를 여러 개(접시 6, 책 여러 권 등)로 부풀려 목표 수를 채움.

  - *이면*: 협탁 서랍 약·숨긴 일기 = 엄마의 감춘 속(고립). 빼둔 결혼반지 + 벽 딸 사진 = 조용한 암시. 침대·바닥 피(첫 등장). 핏자국 배치는 §6.8에서. **종교 물품 없음**(불쾌 소지 배제).

  - *요·이불(4)*: 이불 · 베개 · 담요 · 방석

## 6.7 첫 방 설계 — 딸 방 (상세 · 제작 착수 기준)

**첫 방이자 튜토리얼.** 표면 = 평범한 중학생 방 정리(아늑) / 이면 = **숨었다 도망친 딸의 흔적**(조용한 암시).
> **첫 방은 피·시체 없음 + 공포(이상현상)도 없음.** 오직 **으스스한 분위기만** — 불을 켰는데도 방이 어딘가 어둑하고 채도가 죽어 있음(미묘한 '잘못됨'). "정리 게임인 척"(§10 도입) 유지, 진짜 공포는 **안방(§6.8)부터.** 첫 방만 유일하게 피 없는 방 = 반전 복선(딸은 여기서 안 죽음).

### 진행 흐름 (0 → 완주, 초 단위 요약)
```
0. 시작 화면(제목·앰비언스만) → '새 게임' → 페이드 인
1. 어둑한 딸 방 정면 뷰. 첫 독백 "…어디 갔지."
2. 하단 중앙에 첫 물건(베개) 뿅 → 클릭해 집음(커서가 됨) → 침대에 배치 (프롬프트 1회)
3. 손 비면 다음 물건 등장 → 클릭 → 배치 … (아래 C 순서)
   · 교복: 우클릭 회전해 옷장   · 화장품: 화장대(틀리면 빨강 테두리)
   · 키링 인형: 창틀           · 필통: 책상 서랍 열어 넣기
4. 옷장 열면 안쪽 긁힌 자국(설명 없음) + 독백 "여기도 아니고"(간접 힌트)
5. 마지막 딸 그림 → 벽(안 변함). 진행도 다 채움(~80), 빨강 0
6. 전등 스위치 활성 → 클릭해 불 끔 → 암전 → 페이드 → 안방(챕터2)
```

### A. 화면 레이아웃 (정면 정투영 스케치)
```
벽: [아이돌 포스터2] [사진보드] [딸 그림] [상장]        [창틀]  [전등 스위치]
   ┌───────────────────────────────────────────────────────────────┐
   │ [옷장]                  [책꽂이]     [화장대 겸 책상 + 거울/서랍]    │
   │                                                                 │
   │  [침대] (밑=수납)                          [전신거울]             │
   │        ~ 바닥: 흩어진 소품 (하단 중앙에 하나씩 제시 → 클릭해 집기) ~   │
   └───────────────────────────────────────────────────────────────┘
```
- **정리 존 10개:** 침대 · 침대밑 / 옷장 / 화장대위 · 화장대서랍 · 책상서랍(= 한 가구) / 책꽂이 / 사진보드 / 창틀 / 벽(딸 그림).
- **전등 스위치 = 오른쪽 벽 끝** (완료 후 여기서 불 끄고 전환, §5.5).
- **전신거울 = 오른쪽 구석** (엔딩 현관 거울의 복선 무대 — 딸 방에선 반사 이상 없음).
- 존 위치: 침대·밑(좌) / 옷장(좌상) / 화장대 겸 책상(우) / 책꽂이(중상) / 사진보드·벽(상) / 창틀(우상).

### B. 초기 상태 (어질러짐) → 목표 상태
- **초기:** 옷장 문 반쯤 열림+옷 바닥 · 이불 흘러내림·의자 넘어짐 · 책상 물건 쓸려 떨어짐(필통 쏟아짐·고데기 전선·화장품 굴러다님) · 바닥에 딸 그림 1장.
- **목표:** 옷→옷장, 화장품·헤어→화장대, 책→책꽂이, 키링·선인장→창틀, 이불 정돈 → **도로 아늑한 방.**
- *조용한 암시:* 옷장 안쪽 문에 **손톱 긁힌 자국**(옷 걸려 열면 보임) = 살아서 숨었던 흔적. 핏자국 아님·설명 없음.

### C. 물건 제시 순서 (하단 중앙에 뜨는 순서 = 튜토리얼 곡선)
```
 1 베개       → 침대       [집기·놓기 학습]
 2 교복       → 옷장       [90° 회전 학습 — 옷 걸면 옷걸이 자동 생성]
 3 후드티     → 옷장
 4 스킨/화장품 → 화장대     [카테고리 존 학습 — 다른 존엔 빨강 테두리]
 5 고데기     → 화장대
 6 문제집     → 책꽂이     [존 구분]
 7 교과서     → 책꽂이
 8 필통       → 책상 서랍  [서랍 열기 학습]
 9 키링 인형   → 창틀       [장식 존]
10 딸 그림    → 벽         [여기선 변하지 않음 — 순수 복선. §8 진행은 이후 방부터]
… 이후 나머지 소품 계속 (옷·속옷·화장품·책 등, 총 ~80)
```
> 전체 존·물건 목록은 §6.6(딸 방, ~80/존10) 참조. 위는 튜토리얼 학습 순서만 발췌.

### D. 튜토리얼 온보딩 (조작 학습, UI 최소)
- 각 조작은 **처음 필요한 순간에 짧은 프롬프트** 1회(예: 첫 교복에서 "우클릭: 회전"). 이후 안 뜸.
- 학습: 집기·놓기 → 회전 → 카테고리 존 → 서랍 열기. (실패·오답 페널티 없음)
- 실패·오답 페널티 없음(§3.5 기둥). 잘못된 존엔 그냥 안 놓임.

### E. 분위기 (공포 요소 없음 — 진짜 공포는 안방부터)
- **이상현상·점프스케어 전무.** 딸 방은 순수 튜토리얼.
- 유일한 이질감 = **조명.** 불을 켰는데도 방이 어딘가 **어둑하고 채도가 죽어** 있음. 아늑함과 미묘한 '잘못됨'이 공존.
- **딸 그림:** 밝은 가족 그림(5명 — 아빠·엄마·할머니·삼촌·딸) — 여기선 **변하지 않음.** 순수하게 걸림(캐릭터·복선 심기). §8 그림 진행은 이후 방부터.
- **전신거울:** 그냥 존재(반사 이상 없음). 엔딩 현관 거울(§9)에 '거울을 익숙하게' 만드는 복선 오브젝트로만.

### F. 독백 & 간접 힌트 (§5.5 미스디렉션)
- **M1** (입장 직후): *"…어디 갔지."* — 첫 독백.
- **M2** (옷장 열 때): *"여기도 아니고."* — **간접 힌트.** '없네'가 아니라 '아니고'(장소를 뒤지는 뉘앙스=사람 찾기) → 거의 안 들리게. **이 방의 소급 회수용 힌트.**
- **M3** (거의 다 치웠을 때): *"…없나."* — 여전히 모호(물건? 사람?).

### G. 핏자국 · 완료 · 전환
- **핏자국: 없음** (딸 미살해 — 첫 방만 유일하게 깨끗). = 반전 복선.
- **완료:** 소품 전부 배치 = 100%.
- **전환:** 오른쪽 벽 **전등 스위치 활성화(유도)** → 끄면 방 어두워짐 → 페이드 → **안방(챕터2).** (딸 방은 여기까지 무해 — 공포는 안방부터.)

### H. 프로토타입 최소 셋 (§12)
- 소품 5~6개: 베개·교복·화장품·책·키링 인형 + **딸 그림** (하단 중앙 제시 → 클릭 집기)
- 존 4~5종: 침대/옷장/화장대/책꽂이/창틀
- 조작 4종: 집기·회전·존 배치·서랍 열기
- **이상현상 없음** — 정리 손맛 + 으스스한 조명 분위기만 검증. (첫 이상현상 검증은 안방 §6.8 최소 구현으로)

## 6.8 두 번째 방 — 안방 (상세 · 첫 공포 방)

청소 순서 2번째, **엄마가 살해된 방.** 게임에서 **핏자국·핏자국 닦기·첫 이상현상**이 여기서 등장 → "정리 게임인 척"이 슬며시 깨짐.
> 딸 방(1번)은 피 없음(딸 생존). **안방에서 피가 처음 나오는 게** 반전과 자연스럽게 맞물림.
부부 침실(아빠·엄마 공유). 정보 축 = 엄마의 '매달림'. 정리 대상 ~90개(§6.6). ※아래 A~G는 초안 — 새 목록 기준 ②(순서·이상현상) 재정리 예정.

### A. 화면 레이아웃 (정면 정투영 스케치)
```
벽: [결혼사진]        [벽시계]                       [전등 스위치]
   ┌──────────────────────────────────────────────────────┐
   │ [옷장]         [화장대 + 거울]            [서랍장]        │
   │                                                        │
   │ [협탁·무드등]══[ 더블 침대 ]══[협탁]        [이불장]       │
   │       ~ 바닥: 흩어진 소품 + 핏자국 ~                     │
   └──────────────────────────────────────────────────────┘
```
- 존: 화장대(우) / 협탁 위·서랍(침대 좌우) / 옷장·서랍장(좌·우) / 침대(중, 정돈) / 이불장(우).
- **협탁 서랍(무드등 쪽) = 숨긴 일기** 자리 (서사 + 이상현상 트리거).

### B. 초기 상태 → 목표 상태
- **초기:** 이불 한쪽으로 쏠림·헝클어짐(몸부림) + **시트·바닥·벽에 핏자국**(첫 등장) · 협탁 무드등 넘어져 켜진 채·물컵 쏟아짐 · 약봉지·약통 바닥에 흩어짐 · 화장대 물건 일부 떨어짐.
- **목표:** 옷→옷장, 화장품→화장대, 약·일기→협탁 서랍, 침구 정돈·무드등 세움, **핏자국 전부 닦음** → 고요한 부부 침실.
- *조용한 암시:* 협탁 서랍 반쯤 열림 → 숨긴 일기 삐죽(열면 며느리 고립).

### C. 물건 제시 순서 (핏자국·이상현상 트리거 포함)
```
 1 베개        → 침대
 2 이불        → 침대(정돈)
 3 슬리퍼2     → 침대 밑
★ 핏자국 닦기 프롬프트 — 시트의 핏자국 발견 (첫 닦기 학습)
 4 약봉지      → 협탁 서랍
 5 약통        → 협탁 서랍
 6 수면안대·결혼반지 → 협탁 위
★ E1 트리거 — 협탁 서랍 약 정리 중 '엄마 뒷모습'
 7 스킨·로션   → 화장대
 8 립스틱      → 화장대
 9 향수        → 화장대
★ E3 트리거 — 화장대 앞, 거울에 형체
10 아빠 셔츠   → 옷장
11 스카프      → 옷장
12 양말·속옷   → 서랍장
★ E2 트리거 — 협탁 서랍 열 때 '눈' + 숨긴 일기 발견
13 결혼사진    → 협탁 위
14 무드등      → 협탁 위(세움)
```
> 전체 목록 §6.6(안방, ~90). 위는 공급 순서·트리거 발췌(초안).

### D. 새 조작 — 핏자국 닦기 (첫 도입)
- 새 입력: 핏자국 위에서 **문지르기**(드래그/키). **2~3번 문질러야** 옅어져 사라짐 → "지우는 노동" 감각.
- 첫 핏자국에서 **안내 프롬프트 1회**. 이후 안 뜸.
- 물건 배치와 **자유 병행**(§5.5). 닦은 자국은 **그대로 유지**(안 되돌아옴).

### E. 이상현상 스크립트 (첫 공포 — 강도: 미묘~살짝 대담)
- **E1 「엄마 뒷모습」(핵심, 1~2회):** 트리거 = 협탁 서랍 약 정리 중. 침대 옆/화장대 앞에 **웅크린 뒷모습**, 낮은 흐느낌 → ~2초 후 사라짐. 사운드 = 낮은 숨죽인 소리.
- **E2 「서랍 속 눈」:** 트리거 = 협탁 서랍 여는 순간. 틈으로 **눈**이 잠깐 → 닫으면 없음.
- **E3 「거울 속 형체」:** 화장대 앞 정리 중 거울에 **뒤에 선 형체** 반사 → 화면엔 없음. (딸 방 전신거울 복선의 회수 시작)
- **E4 「딸(구분 불가)」:** 옷장·문틈에 여자애 형체 잠깐 — 귀신인지 산 딸인지 모름(§8).
- (옵션) **딸 그림:** 화장대에 딸이 엄마에게 준 그림 → 여기서 **§8 진행 단계2**(검은 형체 추가)로 변해 있음. 딸 방(단계1)에서 이어짐.

### F. 독백 & 간접 힌트
- **M1:** *"…여기도 없나."*
- **M2 (간접 힌트):** 침대 밑/옷장 열 때 *"밑에는… 없고."* ← **사람 숨을 곳 뒤지는 뉘앙스**(소급 회수용). 거의 안 들리게.
- 숨긴 일기 발견 시 강도는 **무감정** — 반응 없거나 짧은 *"…쯧."*

### G. 핏자국 배치 & 완료·전환
- **핏자국(안방 = 중간):** 침대 시트 1~2 · 바닥 1 · 벽 튄 자국 1.
- **완료:** 소품 배치 + 핏자국 전부 제거 = 100%.
- **전환:** 전등 스위치 → 불 끔 → **첫 '불 끄기 공포 비트'**(불 꺼진 찰나 엄마 뒷모습/숨소리 한 번) → 페이드 → **화장실(챕터3).**

### 핏자국 양의 점증 곡선 (전체 참고)
```
딸 방(0) → 안방(첫 등장·중간) → 화장실(씻은 흔적: 세면대·욕조·수건)
→ 서재·계단(몸싸움·최다) → 할머니 방(자다 당함·중간) → 주방(0~옅음)
→ 거실(삼촌·적음, 클라이맥스 무대) → 현관(0)
```
→ 뒤로 갈수록 양·강도 ↑. 몸싸움 있던 서재·계단이 피 최다. 화장실은 '자기 흔적'이라 결이 다름.

## 7. 스토리

### 설정
- **주인공 = 강도.** 이 집에 침입해 어른 4명(삼촌·할머니·아빠·엄마)을 **살해**했다.
- **딸(막내·중학생)은 죽지 않았다.** 비명·소리에 집 어딘가로 숨었고 강도는 **끝내 못 찾았다.** → 게임 내내 딸은 **살아서 숨어 있음.**
- 강도는 4구의 **시체를 지하실에 옮겨 숨기고**, 지금은 방마다 **범행 흔적을 지우면서 동시에 숨은 딸을 찾는 중.** (그래서 게임 중 시체는 안 보임)
- 이 가족은 이미 **무너지기 직전**이었다(빚·절망). 강도가 든 그날 밤, 최후의 비극이 겹쳤다. → **이중 비극.**

### 구조: 방 = 가족 구성원
한 집의 여러 방을 정리하며 **그날 밤 무슨 일이 있었는지**가 조립됨. 각 방이 한 명의 시점·감정.
```
할머니 방    — 두 아들을 둔 집안의 뿌리, 다 잃는 어머니 (제사상·흑백 가족사진·낡은 세간)
아빠 서재    — 성실한 가장의 겉모습, 서랍 속 빚 독촉장·해고 통지 (형의 빚까지 떠안음)
안방(부부)   — 아빠·엄마 같이 씀. 며느리 엄마의 고립 (약·숨긴 일기)
딸 방        — 손녀, 막내(중학생), 그림·낙서·일기에 진실이 드러남 (꾸미기 좋아하는 평범한 일상 ↔ 잔인한 진실의 대비)
거실/식탁    — 가족이 마지막으로 함께 있던 자리(클라이맥스) + 삼촌이 얹혀사는 곳
             삼촌 = 아빠의 형(미혼, 손녀는 삼촌이라 부름), 이 집을 빚으로 끌어들인 장본인.
             방 없이 거실에 물건 몇 개(술병·차용증·독촉장·현금 봉투)로만 존재.
```

### 그날 밤 타임라인 (확정)
강도가 침입한 뒤 벌어진 순서 — 아래층에서 위층으로 훑어 올라감:
```
1. 거실 — 삼촌   : 술 먹고 TV 틀어놓은 채 잠든 삼촌을 무방비로 살해 (첫 희생자, 무방비)
2. 할머니 방     : 자고 있던 할머니 살해
3. 계단 — 아빠   : 시끄러운 소리에 서재에서 작업하다 나온 아빠를 계단쯤에서 살해
4. 안방 — 엄마   : 안방에 있던 엄마 살해
5. 딸        : 비명에 놀라 집 어딘가로 숨음 → 강도가 끝내 못 찾음 (미살해·게임 내내 생존)
```
→ 강도는 어른 4구를 **지하실에 옮겨 숨기고**, 딸을 찾으며 흔적을 지우기 시작 = **게임 시작 시점.**

### 방별 범행 흔적 (정리 = 인멸 대상)
```
거실     : 소파·바닥, 넘어진 술병·켜진 TV. 무방비 → 흔적 적고 조용함.
할머니 방 : 침대·이불·베개. 자다 당함.
계단·서재 : 유일한 몸싸움 흔적(부서진 것·계단의 피) → 아빠 '분노' 이상현상과 직결.
안방     : 엄마의 마지막 자리.
딸 방    : 옷장 = 딸이 숨었다 도망친 곳(살아 있음). 몸싸움 아닌 '급히 숨은/빠져나간' 자국.
```

### 공포 원칙
가장 순수한 시점(딸)에서 가장 잔인한 진실이 나온다.

### 미스디렉션: 독백으로 딸 찾기 (핵심 반전 장치)
- 게임 내내 주인공이 **가끔 독백** — 짧고 모호하게. 첫 방 *"…어디 갔지."* 이후 *"아직인가"* · *"여기 어딘가 있을 텐데"* · *"찾아야 하는데"*.
- **절대 '딸'·'아이'라고 말하지 않음.** 플레이어는 *중요한 물건*을 찾는 줄 앎.
- 진실: 강도는 **못 죽인 딸**을 찾는 중. 최종 선택 순간(§9)에 정체가 드러남 = **반전.**
- 얼핏 보이는 형체(§8)에 **살아있는 딸의 실제 목격이 섞여** 있음 — 귀신인 줄 알았던 게 일부는 진짜였음.

## 8. 공포 엔진: 지켜보는 가족 (이상현상)

### 대원칙
- **정리(인멸)는 정상적으로 완수됨.** 치운 소품·버린 쓰레기·닦은 핏자국은 **그대로 유지**된다. **되돌아오지 않음.** (정리 손맛 보존 — 되돌리기 저항 폐기)
- 공포는 **별개 레이어 = 이상현상.** 죽은 가족은 널 **막지 않는다. 다만 계속 지켜보고, 잠깐씩 나타난다.**
- 핏자국 = 닦아야 할 범행 흔적(닦으면 닦임). 이상현상 = 그 위에 얹히는 초자연 목격.
- **구분 불가 트릭:** 얼핏 보이는 형체엔 죽은 가족(귀신)과 **살아있는 딸(실제 목격)이 섞여** 있음. 플레이어는 못 가림 → 최종 반전(§9) 때 "일부는 진짜였다"로 회수.

### 이상현상 3유형
```
1. 인터랙션 트리거 — 특정 행동에 반응해 잠깐 나타났다 사라짐
   · 서랍을 열면 그 틈으로 눈이 잠깐 보였다 사라짐
   · 액자를 걸면 사진 속 눈에서 빨간 눈물이 흐름
   · 옷장을 열면 안쪽에 누가 서 있음 (다시 보면 없음)
2. 주변시야 스침 — 시야 가장자리로 형체가 지나감. 돌아보면 없음.
3. 응시 — 어딘가에서 공허하게 널 노려봄
   · 책상 아래 여자애가 쭈그리고 앉아 노려봄
   · 거울·창문·TV 반사에 뒤에 선 형체
```

### 점층 (강도만 올라감, 정리 자체는 그대로 완수됨)
1. **미묘** — 스침·짧은 깜빡임. "…방금 뭐였지?"
2. **대담** — 대놓고 나타나 잠깐 머무름. 응시가 길어짐.
3. **엔딩 포위** — 현관 거울에서 온 가족이 동시에(§9). 목격의 최종 형태.

### 가족별 이상현상 색깔 (누가·어떻게 나타나나)
```
아빠  — 부서진 물건·계단 그림자, 분노한 얼굴이 스침 (분노)
삼촌  — 거실 TV·구석에 술 취한 듯 흐릿한 형체 (무기력·죄)
엄마  — 약·협탁 곁에 웅크린 뒷모습, 낮은 흐느낌 (매달림)
할머니 — 제사상·흑백사진에서 응시, 사진 속 눈이 움직임 (한·집착)
딸   — 가장 자주·가장 가까이. 책상 밑·옷장·그림 속에서 지켜봄 (귀신 아님 — 살아서 숨은 채 훔쳐보는 실제 목격이 섞임)
```

### 딸 그림 (핵심 소름 장치) — '되돌아옴'이 아니라 '변해 있음'
치우는 것과 무관하게, 마주칠 때마다 그림이 **다르게 그려져 있음**:
1. 밝은 가족 그림 (5명 — 아빠·엄마·할머니·삼촌·딸)
2. 검은 형체 하나 추가 (=너)
3. 가족은 누워있고 검은 형체만 서 있음
4. 그림이 널 향해 삐뚤빼뚤 **"왜?"**

## 9. 반전 & 엔딩 (확정)

### 진짜 반전: 찾던 건 딸이었다
모든 방 정리 완료 → 마지막 순간 **딸의 은신처가 드러남**(위치 미정 — 엔딩 단계에서 결정). 이 순간, 게임 내내 독백으로 찾던 '무언가'가 **살아 숨어 있던 막내딸**이었음이 밝혀짐. = 미스디렉션의 폭발.

### 최종 선택 (분기) — 명시적 선택지 → 컷신
플레이어에게 선택지 제시. 실제 살해/매장·검거는 인터랙티브가 아니라 **선택 후 컷신(애니메이션 또는 일러스트)** 으로 전개.
```
[ 죽인다 ]  → 컷신: 딸 살해 → 지하실로 옮겨 매장
             → 거기 이미 어른 4구가 묻혀 있음이 드러남 (게임 중 시체가 안 보였던 이유)
[ 떠난다 ]  → 컷신: 딸 생존 → 신고 → 강도 경찰 검거
```

### 거울 엔딩 (두 분기 공통)
1. (분기 컷신 후) **현관 → 신발장 옆 작은 거울.** 게임 내내 모든 정리는 완벽히 됐는데, **거울만 유일하게 안 먹힘.** "다 됐는데 이것만 안 됨."
2. **나레이션 (확정안 C):** *"흔적은 지웠다. …기억은, 여기 남아서 나를 본다."*
3. 거울 속 **내 뒤 어둠**에서 죽은 가족이 **동시에** 스르륵 떠오름.
   - **[죽인다] 분기 → 딸까지 5명** (방금 죽인 딸 포함).
   - **[떠난다] 분기 → 4명** (딸은 살아 있음).
4. **거울에만 보임.** 실제 화면엔 아무도 없음 → 뒤돌아볼 수도 없음.
5. (딸 있는 분기면) 딸의 손이 어깨에 닿기 **직전** → **암전.**
6. 소리만: 여러 겹 숨 들이쉬는 소리 / 날카로운 소리 / **완전한 무음.** 끝.
> ※ 검거 분기의 현관 거울 연출(호송 중 반사 등 무대)은 엔딩 단계에서 마감. 딸 은신처 위치도 이때 확정.

### 주제
**"물건은 정리할 수 있어도, 내가 한 짓은 정리할 수 없다."** 그리고 — 정리 게임인 줄 알았던 플레이어는, 사실 **숨은 아이를 사냥하고 있었다.** 마지막 선택이 그 진실을 들이민다.

### 사운드 원칙 (엔딩의 90%)
- 거울까지: 완전한 정적
- 나레이션: 무감정한 톤 (죄책감 없음 = 더 무서움)
- 귀신: 저주파 웅 + 여러 겹 숨소리
- 암전: 한 번의 날카로운 소리 → 무음

## 10. 전체 뼈대
```
도입   — 강도가 청소하러 + "…어디 갔지" 독백 (플레이어는 물건 찾는 줄)
전개   — 방마다 정리 = 증거 인멸, 이상현상 시작 (미묘) + 찾기 독백
점층   — 이상현상 대담·구분 불가한 형체, 지켜보는 가족
절정   — 딸 은신처 드러남 → 찾던 게 산 아이였다 (반전)
선택   — [죽인다] / [떠난다] 분기 컷신
결말   — 지하실 매장 or 경찰 검거 → 현관 거울, 가족, 암전
```

## 12. 프로토타입 최소 범위 (첫 목표)
**대상 방 = 딸 방 (§6.7 H 참조).**
1. 평면 정투영 방 1개 = 딸 방 (Blender 정상 상태 렌더 + 살짝 어둑한 조명)
2. 물건 5~6개: 베개·교복·화장품·책·키링 인형 + 딸 그림 — **하단 중앙 제시 → 클릭 집기** → 90° 회전 → 존 배치(틀리면 빨강) → 진행도(n/N)
3. 정리 완료 판정 (존: 침대/옷장/화장대/책꽂이/창틀 등) → 불 끄고 전환
4. **딸 방엔 이상현상 없음** — 정리 손맛 + 으스스한 조명 분위기 확인.
→ 여기까지 되면 **안방(§6.8) 최소 구현**으로 확장: 핏자국 닦기 + **첫 이상현상**(엄마 뒷모습 등)이 '첫 오싹함'이 되는지 검증.
